# 技术计划：Agent 上下文压缩

状态：首版实现与自动化验证已完成；真实账号和浏览器待验收。

1. 预算与投影：服务端环境变量 `AGENT_COMPACTION_BUDGETS` 为严格 JSON，按精确 upstreamModel 配置 contextWindow/maxOutputTokens/keepRecentTokens/summaryTokens/safetyTokens；无配置模型不自动摘要，已有摘要仍用于投影。UTF-8 字节保守估算，包含系统/工具/动态上下文和协议余量，不宣称精确 tokenizer。
2. 摘要：合法用户区间切分、完整工具配对、旧摘要加新增历史；摘要输入分批预算，失败/取消不提交。使用当前账号 Key、本轮模型与 AI SDK generateText，不提供工具。
3. 会话一致性：每次 HTTP run 前持久化浏览器快照并携 expectedVersion；服务端按完整快照和版本核对。摘要 CAS 后发送版本事件；任何终止路径再读取持久化快照，确认是已保存快照才同步版本，保留本地生成结果。
4. 存储：保护已覆盖历史，防止普通保存令摘要失效；摘要状态验证非空、合法边界、前进；复用既有 SQL 字段，无新迁移。
5. 前端：稳定保存队列、三请求并发回归、取消过期定时重试、发送/新建/切换/删除互斥、关闭前 flush。工具仍在浏览器执行。
6. 验证：纯算法与失败单测、真实隔离 PostgreSQL 集成与路由测试、两端类型/测试/构建；只用临时测试库，不使用应用库，不修改真实 Key 或环境文件。
