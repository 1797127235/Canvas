- 工作流模板预览：打开模板弹窗应立即显示画布和节点，图片、视频由浏览器按模板静态地址各自加载，不再先转圈等待全部原始媒体下载完成；视频仍可播放。点「克隆并编辑」后，原始图片和视频应下载并上传到当前账号，新画布中的媒体可查看、可播放。

- 工作流模板：模板库「工作流」分类应显示内置工作流模板卡片（封面、作者、标签），搜索关键词和标签筛选对模板同样生效。配置了成果视频的模板，鼠标悬停卡片应懒加载并静音循环播放成果视频，鼠标移开后停止播放并回到封面图；点击卡片应在弹窗中打开只读预览：弹窗标题下方显示「克隆后可修改素材、文案和节点参数」，右上角为「克隆并编辑」按钮；画布自动缩放居中显示全部节点，可平移缩放，图片正常显示、视频可播放，悬停节点不出现标题提示词、下载按钮或连线圆点等任何工具。点「克隆并编辑」后应关闭弹窗并生成一个新画布自动进入：节点、连线、提示词、生成参数齐全，图片可查看、视频可播放、连接自己的渠道后可重新生成；模板本身保持不变。

- 模板库入口：顶部导航和页面标题显示「模板库」；类型包含「提示词」和「工作流」，提示词分类展示原有内容，工作流分类显示为空；数量显示「当前共 N 条模板」。提示词卡片底部不再显示「复制」和「加入我的资产」；点击卡片打开详情后，仍可复制提示词和加入资产。详情底部的「用于生图」「用于生视频」应分别进入图像工作台和视频工作台，并把该提示词填入输入框，不自动开始生成。

- 本地代理移除：配置弹窗不再显示「本地代理」页签，模型列表、生图、生视频、文本和音频请求都直接发给渠道地址。

- 偏好设置移除：配置弹窗不再显示「偏好设置」页签，只保留渠道、提示词来源和本地存储。

- WebDAV 移除：配置弹窗不再显示 WebDAV 页签，也不再提供测试连接和立即同步；画布、素材和生成记录只保存在浏览器本地。导出的配置不再包含 WebDAV 凭据。

- 界面语言：顶部不再显示中/EN 切换按钮，页面、配置弹窗、Ant Design 组件和日期时间都固定为简体中文。

- 本地渠道文件：在 `web/public/local-channels.json` 写入渠道地址、Key 和模型后刷新页面，配置里应出现对应渠道；已有同一地址和 Key 的渠道只补缺失模型，不重复创建。文件不存在或内容非法时不应改动现有配置。

- 统计与上游清理：应用不再加载 GA4/百度统计脚本、不发送统计请求；Docker 镜像不再生成 config.js，`ANALYTICS_*` 环境变量不再生效；文档站不再包含商务合作、赞助支持和 Render 部署页面；仓库移除上游发布用 GitHub Actions、Render/Vercel 部署配置和赞助商素材。

- 画布图片预览：画布图片节点、左侧元素列表、节点参考栏、我的资产卡片、资产选择弹窗、生图工作台的结果卡片与历史缩略图、生图和视频工作台的参考图都使用最大边长 768px 的缩略图渲染，使图片较多时不再反复解码原图。缩略图只存在本地，画布数据、资产数据、生图历史和导出包里都不应出现缩略图内容，删除图片或用不到时也应一并清掉。点开大图、编辑、下载、导出和生成参考图必须继续使用原始图片；图片本身不超过 768px、只有远端地址（跨域读不到本地内容）、或使用自定义封面时应回退原图。

- 画布拖拽与连线渲染性能：单选、多选、拖动整组节点时位置跟手，松手后落点与拖动过程一致；把节点拖到组上方时组高亮出现和消失的时机正常，松手能正确加入组，拖出组也能正确移出；组节点自身被拖动时不应出现组高亮。画布缩放和平移到只显示局部时，视口内的连线应完整显示（包含两端节点都在视口外、但曲线穿过视口的连线），连线的点击选中和右键菜单仍可用，连线拖拽创建过程中的虚线跟随正常。

- 图像与视频尺寸设置：图像设置应将分辨率（`1k` / `2k` / `4k` / 自动）和宽高比（`1:1`、`2:3`、`3:2`、`4:3`、`3:4`、`16:9`、`9:16`、`21:9`、`9:21`、自动）拆成两项，并由二者计算 W/H。视频设置仍使用 `480p` / `720p` / `1080p`（以及自定义 p 值），比例为 `1:1`、`3:4`、`4:3`、`16:9`、`9:16`、`21:9`、自动，并由清晰度与比例计算 W/H。秒数应为 4–30 的滑杆，右侧显示当前秒数；比例为自动时应禁用 W/H。

- 视频内置请求：未配置调用脚本时，OpenAI 格式应按模板发送 `mode`、`first_frame`/`last_frame` 或 `image[]`、`generate_audio`、`watermark` 以及参考视频/音频，不再使用 `input_reference[]`；Gemini 格式应走 `predictLongRunning`，按模式发送 `image`/`lastFrame` 或 `referenceImages`，不再提示不支持视频。刷新后应能继续查询 Gemini 任务状态。

- 视频生成模式：视频设置应出现「首尾帧」和「全能参考」；1 张图按首帧、2 张图按首尾帧发送专门字段，超过 2 张即使选了首尾帧也按全能参考发送。内置请求和调用脚本的 `params.mode` 均为 `frames` 或 `reference`。

- Gemini 生图：Gemini 格式渠道和 Gemini 生图调用脚本应使用 `generationConfig.responseModalities: ["TEXT", "IMAGE"]`，比例和尺寸放在 `imageConfig.aspectRatio` / `imageConfig.imageSize`，不再发送 `responseFormat`。

- 视频调用脚本：能力为「视频」的模型打开「调用脚本」后应进入全屏分步配置；左侧按「看懂规则 → 让外部 AI 写 → 可用变量」展示，可用变量应包含 `videos`（参考视频 File 数组）和 `audios`（参考音频 File 数组）；「复制写脚本说明」应包含当前能力、可用变量、返回要求和写法约束。插入的模板应是带参数列表的 async function，并把 `params` 拆开；OpenAI 生图模板必须包含 `quality`、`size`、`count`、`background`。OpenAI 视频模板应使用 FormData，带上 `mode`、时长、尺寸、分辨率、配音、水印以及参考图/视频/音频；`mode=frames` 时应使用 `first_frame` / `last_frame`，`mode=reference` 时应使用 `image[]`，完成后轮询并下载 `/content`。把外部 AI 写好的脚本粘贴到右侧并保存后，画布连接参考视频或参考音频再生成时，脚本应能读取这些文件。

- URL 凭据导入：使用新的有效 `baseUrl` 和 `apiKey` 打开应用时，应新增独立渠道且不修改已有渠道；再次导入相同 Base URL（含末尾斜杠或 `/v1`）时只更新对应渠道并保持幂等；仅提供 API Key 或提供非法 Base URL 时，所有配置都应保持不变。

- 文档站导航与本页目录：手机宽度打开文档侧边栏时，顶部应显示当前文档分类及说明；展开后可在项目介绍、操作手册、开发文档、项目进度、商务合作和赞助支持之间切换，切换后分类标题及下方页面列表应同步更新；桌面端顶部分类栏保持不变，宽度达到 960px 时正文右侧应显示带层级折线的本页标题目录，点击可跳转，滚动时自动高亮当前标题；较窄宽度继续显示顶部折叠目录。

- 视频画面截取：右键有内容的视频节点应显示「截取首帧」「截取尾帧」「截取当前帧」；三项操作应按视频原始比例在右侧生成并选中图片节点，同时建立视频到图片的连线；「截取当前帧」应使用播放器此刻停留的画面，截取过程不得改变原视频的播放位置。

- 文本节点：节点正文右上角不再显示「生图」按钮，文字内容应使用完整正文区域；节点上方工具条中的生图入口仍可正常创建生成配置。

- 多文本生成：生成次数大于 1 时只创建一个文本结果节点和一条来源连线；节点右上角显示实际生成成功的文本数量，点击后应像多图节点一样展开所有备选文本；点击「设为主文本」应立即替换正文，原主文本保留为备选，双击正文编辑后再次切换回来仍应保留修改。

- 组节点引用：组节点应使用透明、轻量的边框与标题样式，并显示右侧输出连接点；把组连接到生成节点后，组内有内容的图片、视频、音频、文本及其他支持引用的内置节点都应作为输入，普通提示词面板的 `@` 列表应显示组内资源，生成配置的 `@` 列表应允许一次选择整组；组与单节点重复引用时不得重复发送同一资源。

- 多选打组：框选或点选至少两个节点后，应出现包住全部选中节点的圆角虚线框，框上方显示「打组」；点击后用组节点包住这些内容并保持原位置，随后选中该组。选中组后可通过顶部「解散组」、右键菜单或 `Ctrl/Cmd+Shift+G` 取消分组；已同属一组的节点再次多选时应显示「解散组」而不是再打一组。拖入组、组引用和左侧树形列表应继续可用。

- 节点参考栏：普通节点提示词面板、放大编辑器和生成配置输入框上方应显示当前输入节点；图片和视频显示缩略图并可悬停预览，文本、音频及其他支持引用的内置节点显示对应类型；组连接应展开显示组内每个有效内容节点，删除任一展开项都应断开整组连线。点击加号进入画布选择后可连续添加有效参考，已连接、目标自身、已通过组引用的组内节点及不可引用节点不可重复选择，按 ESC 或顶部提示返回输入框；新增连接后 `@` 列表应立即更新。

- 多图透明背景：展开包含透明 PNG 或 WebP 的多图节点时，主图与所有备选图的透明区域都应直接显示画布背景；切换主图前后不得出现白色或主题面板底色。

- 画布选择与平移：左下工具栏应能切换「选择」与「移动」模式并用图标显示当前模式；选择模式拖动空白区域应显示疏朗清晰的虚线框，虚线长度、间距和粗细在任意缩放比例下保持一致；移动模式应能从空白区域或节点上拖动画布。按住 Control 或空格应临时反转当前工具且不改变工具栏模式，即选择变移动、移动变范围选择；点击画布页任意按钮后按空格应只临时切换工具，不得再次触发该按钮；输入框和可编辑文本内仍可正常输入空格。中键平移以及 Shift/Cmd 追加选择节点应继续可用。

- 文档站国际化：访问文档站首页及 `/docs` 应直接显示英文，不得出现重定向循环；切换简体中文后 URL 应带 `/zh-CN` 且首页、顶部导航、侧边栏、正文、搜索框和页面操作文案均显示中文；刷新、站内跳转和再次切回 English 后语言应保持正确，搜索结果与 Markdown/LLM 文档内容不得混入另一种语言。

- 国际化基础框架：从页面右上角切换简体中文或 English 后，首页、顶部及移动端导航、版本弹窗、配置主面板、渠道编辑、模型选择、页面标题、页面描述和 Ant Design 内置文案应立即切换，刷新页面后保持所选语言；提示词来源及其他尚未接入翻译的业务模块暂时仍可能显示中文。

- 全局弹层主题：全站 Dropdown、Menu、Select、Cascader、TreeSelect 等弹层在浅色主题下应使用白色背景、轻灰悬停和选中态，在深色主题下应使用深色背景与低对比度浅色交互态，不应再出现默认黑灰色块、文字对比不足或单个页面配色不一致。

- 画布节点缩放稳定性：选中任意节点并反复拖动四角缩放时，节点工具条应在缩放期间隐藏、松开后恢复，页面不应再出现 `Maximum update depth exceeded`。

- 图片 API 模型参数：`gpt-image-*` 的生成和编辑请求不应发送 `response_format`，`dall-e-*` 请求仍应发送 `response_format: "b64_json"`。

- 图片外链持久化：画布和生图工作台对图片接口返回的远程 URL 应只下载一次，经图片解码校验后保存到 IndexedDB；返回 `200` 但内容不是图片时应失败，下载期间停止画布生成后不得保存或应用结果；浏览器因 CORS 无法读取但图片仍可显示时，应保留原 URL 且不生成空 `storageKey`，插件调用在外链可读取时仍应收到 Data URL。

- 多参考图编辑：OpenAI 格式在多张参考图时应使用重复的 `image[]` 表单字段提交文件，单张参考图仍使用 `image`；新建的 OpenAI 图片脚本应使用相同字段名。Gemini 渠道和已经保存的自定义脚本不受影响。

- 画布文本复制：在节点信息详情中用鼠标选中文字后，按 `Ctrl/Cmd + C` 应复制所选文本，不应触发画布节点复制；未选中文字且焦点位于画布时，原有节点复制快捷键应保持可用。

- 画布文本设置：文本节点和生成配置节点切换到文本模式后应显示推理强度设置，可选择自动、低、中、高、极高；选择自动时默认 OpenAI Responses 请求不应携带 `reasoning`，选择其他档位时应携带所选强度，刷新画布后节点设置应保留；文本模型自定义调用脚本应能读取 `reasoningEffort`，OpenAI 模板应按自动或指定档位正确组装请求。

- 生图工作台参考图：将一张或多张图片拖入参考图区域后应直接上传并显示缩略图；拖入非图片文件应忽略，拖动过程中区域应显示高亮提示，放下文件不应导致浏览器打开或替换当前页面。

- 工作台历史图片清理：生图或视频工作台生成内容后，在「我的素材」删除图片、删除画布图片节点、清空画布或删除画布，再次打开对应生成记录时，历史缩略图、结果图片和参考图仍应正常显示；删除生成记录时，其专属本地文件仍应正常清理。

- 视频创作台参考资产：将图片、MP4/MOV 视频或 MP3/WAV 音频拖入任一参考资产区域后，应按文件类型自动上传到对应列表；当前拖入区域应显示高亮提示，原有数量、大小、时长和格式限制应继续生效。

- 画布组装提示词：输入或连接超长提示词后，浮层正文高度不应继续撑大，内容应可在正文区域内滚动查看和编辑，标题及关闭按钮保持可见。

- 画布节点提示词：图片等节点下方的提示词超过输入区域高度后，鼠标悬停在输入区域内滚动应查看提示词内容，不应缩放画布。

- 画布节点提示词回显：单图或多图生成完成后，切换选择生成结果的根节点及任一子节点，下方输入区域都应继续显示生成时的提示词；切换到其他节点再选回来后也不应清空。

- 画布生成配置：连接文本节点后连续点击生成（包含失败重试），组装提示词不应重复追加上游文本；在生图、文本、视频、音频之间切换时，实际请求应始终使用当前面板展示的对应类型模型。

- 画布多图生成：开始生成 N 张图片后应立即创建一个包含 N 个可展开槽位的图片节点，并且来源到结果只保留一条连线；生成期间空槽位应独立显示生成中或失败，任何已有图片内容的槽位都必须始终显示图片，任意图片率先成功后应立即成为主图并展示，不等待其他请求完成；收起状态应最多显示三层紧密错开的背板，避免占用过多画布空间，右上角应显示醒目的「N 张」数量提示；点击数量后，浮动工具条应暂时隐藏，各图片槽位应从当前节点向右上方整齐展开；已成功图片的「设为主图」应常驻显示，并在亮色、深色主题及不同图片背景上保持清晰；点击画布空白处应自动收起并恢复工具条。

- 画布多图主图切换：点击「设为主图」后，节点中心和当前最长边应保持不变，仅按新图片比例调整另一条边；自由变形节点应完全保持现有宽高，画布视口及左下角缩放值不应变化。

- 画布多图失败槽位：包括当前主槽位在内的每个失败槽位都应显示「重试」和「删除」；重试只更新当前槽位，已有成功主图时不得抢占主图；删除只移除当前失败槽位并同步更新图片数量。

- 画布多图尺寸调整：子图展开时开始拖动尺寸控制点，应先收起图片组一次，再正常调整根节点尺寸，不应触发 React 循环更新或应用错误页。

- 画布左侧元素列表：点击元素整行应平滑定位并选中对应节点，自动缩放不得超过 100%；有内容的图片元素应显示预览按钮，点击后打开大图弹窗且不触发画布定位。

- 配置与用户偏好：导出 JSON 后应包含渠道、默认模型、生成偏好和提示词来源，不应包含 WebDAV 配置；在修改当前配置后重新导入该文件，应恢复导出时的设置，错误 JSON 文件应提示格式不正确。配置文件包含 API Key，不应公开分享。

- 本地存储设置：配置页应显示「本地存储」Tab，进入后只读取 `infinite-canvas` 数据库，自动统计 IndexedDB 占用、站点总占用、浏览器配额与使用率，并按对象仓库显示记录数及内容体积；新增或删除图片、音视频、生成记录后点击刷新，数据应同步变化，统计期间页面保持可操作。

- 生成提示词的文本编号：普通节点或生成配置连接多个文本节点后发起生成，附加在提示词末尾的每段上游文本都应以「【文本1】」「【文本2】」开头并按连接顺序编号，编号与提示词里 `@` 引用及参考内容栏显示的一致；单段文本同样要带编号，图片、视频、音频编号不受影响。

- 局部遮罩编辑：弹窗底部应为「重置」「导出到画布」「立刻生成」；两个按钮都要求已涂抹区域并填写修改要求，「导出到画布」只写入节点和连线不发起请求，结果节点的提示词面板应预填拼好的提示词并可手动生成，「立刻生成」在写入节点后立即生成。涂抹区域并填写修改要求后确认，画布应在原图下方生成一个「遮罩标注」图片节点，内容为原图叠加半透明蓝色标注区域，颜色和透明度应与弹窗里涂抹时看到的一致；结果节点在原图右侧生成，并同时接收来自原图和遮罩标注的两条连线。请求应按普通参考图发送两张图片，提示词按「图片1 / 图片2」编号说明原图和标注区域，不再携带 mask 参数，Gemini 格式渠道也应可用；生成结果只改动标注区域，且不得残留蓝色标注。

- 图片编辑弹窗：遮罩、切图和裁剪连续滚轮缩放时，图片与遮罩应保持同步且不再闪烁、短暂消失或跳动；遮罩画笔圆心应始终固定在鼠标位置，仅直径随缩放变化，缩放后仍可准确涂抹、拖动切分线和调整裁剪框。

- 提示词中心布局：页面标题及提示词总数应居中；连续输入搜索文字时应在停止输入约 300ms 后再查询；桌面端分类与标签应在左侧独立滚动，右侧搜索框下直接展示提示词卡片；标签数量较多时不能继续向下挤压提示词，窄屏下应恢复上下排列且内容不溢出；不再显示「我的提示词」Tab，收藏提示词应直接加入我的资产。

- 提示词详情弹窗：封面和参考图应固定显示在上方，复制及加入资产操作栏固定在底部，只有中间的标签、描述及提示词内容区域可以滚动；弹窗宽高应受视口限制且不超出屏幕。

- 提示词来源：7 个内置来源应从 Image Prompts 统一仓库读取，更新后数量依次为 323、494、517、53、76、126、129；提示词仍按 7 个来源分组并可独立启用，来源内可继续按 `tags` 筛选。添加标准 JSON URL 后应能查看内容，填写非数组 JSON 或不可访问地址时应显示失败，并继续保留该来源上一次成功缓存的内容。

- 提示词来源界面：来源应以卡片列表展示，启用开关位于左侧，数量、同步状态和上次成功时间作为次级信息显示，查看、拉取及自定义来源编辑/删除操作使用带文字按钮；底部定时拉取区域应保持独立边框布局。

- 画布提示词库：不应再显示「我的提示词」分组；不展开任何公共来源直接搜索其中的提示词，匹配项应自动显示；点击「插入画布」后应创建正文正确且标题保持为提示词标题的文本节点。

- 跨域提示：生图、视频或音频请求被浏览器跨域策略拦截时，应明确提示需要通过自己的服务转发请求，不再只显示笼统的网络错误。

- 资产图片下载：我的资产中仍可预览的图片，点击「下载图片」应能保存文件；标题含中文、空格或「【】」时应沿用原标题作为文件名，无需改名；从画布刚存入、尚未刷新页面的图片也应能下载。

- 画布视频任务恢复：开始 OpenAI 风格视频生成后，视频节点应保存远端任务 ID。刷新页面后，尚未完成的视频应自动继续查询状态；若查询已停止，可点击「获取任务状态」继续用该任务 ID 拉取，直到生成成功、任务失败或查询请求报错。任务失败后，「重试」应重新发起生成而不是继续查旧任务。

- 在画布和图像工作台逐项切换 3 档分辨率与 9 种比例，W/H 应与表格一致，重新打开设置后仍选中正确档位；重点检查 1K 的 2:3、16:9、21:9 及对应竖图，以及 4K 的 1:1。

- 所有 4K 预设提交时均不应触发本地总像素或最长边限制；生成和编辑请求、调用脚本应收到所选像素尺寸。

- 分辨率为自动时保留比例选择，比例为自动时禁用 W/H；手动输入 W/H 后，对齐开关仍应按原有方式工作。

- Gemini 在质量为自动时，应将表中尺寸识别为对应的 1K / 2K / 4K；显式选择质量时维持原有优先级。视频尺寸设置应保持原有行为。
